# 🔐 InformationKeeper (Screenshots are below)

**Your personal, encrypted information manager. Store sensitive data like account credentials, private notes, or photo albums — all protected behind your own secure login.**

---

## 🧾 What You Can Do

- 👤 **Sign Up / Sign In**: Create a personal account with a username, password, and avatar.
- 🔑 **Store Secure Data**:
  - Account credentials (e.g., for social media, apps, websites)
  - Personal notes
  - Private photo albums
- 🔒 **Encryption**: All stored data is encrypted to ensure privacy and safety.
- 🔐 **Password Protection**: Only you can access your information after logging in.
